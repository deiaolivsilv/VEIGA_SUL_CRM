## 📋 Sobre o Projeto

O **Veiga Sul CRM** é um sistema feito para organizar o dia a dia da equipe comercial. Ele funciona como uma pasta digital onde você pode cadastrar potenciais clientes (chamados de *leads*), acompanhar em qual etapa da venda cada um está, marcar reuniões na agenda e ver o desempenho das vendas através de gráficos fáceis de entender.

A grande vantagem é que o sistema salva as informações direto no seu navegador de internet, ou seja, **não precisa de um banco de dados complexo instalado** para começar a testar ou usar!

---

## ✨ Principais Funcionalidades

- 📊 **Painel de Controle (Dashboard):** Gráficos simples que mostram quantos clientes estão em atendimento, o valor total das vendas e o canal por onde eles chegaram.
- 🗂️ **Painel Visual (Kanban):** Uma tela com colunas onde você pode arrastar e soltar os clientes para mudar a fase da venda (desde o primeiro contato até o fechamento do contrato).
- 👥 **Cadastro de Clientes (Leads):** Uma lista organizada para cadastrar, editar, buscar e ver as informações detalhadas de cada contato.
- 📅 **Agenda de Compromissos:** Um calendário integrado para marcar reuniões, ligações e compromissos importantes com os clientes.
- 🔍 **Busca Rápida:** Pressione as teclas `Ctrl + K` no teclado para pesquisar e encontrar qualquer cliente instantaneamente.
- 🌙 **Modo Escuro:** Opção para mudar as cores do sistema para um tom escuro, facilitando a leitura e diminuindo o cansaço visual.

## 🚀 Como Rodar o Projeto no seu Computador

### Pré-requisitos
Você vai precisar de:
1. **Node.js** instalado no computador (versão 18 ou superior).

### Passo a passo
Abra o seu terminal (ou prompt de comando) e siga os passos:

```bash
# 1. Entre na pasta do projeto
cd VEIGA_SUL_CRM

# 2. Instale os componentes necessários
npm install

# 3. Inicie o sistema
npm run dev
```

Após rodar o último comando, o sistema vai abrir no seu navegador pelo endereço:
👉 **http://localhost:5173**

## 🛠️ Tecnologias Principais
Para quem tiver curiosidade técnica, o projeto foi construído usando ferramentas modernas e leves:

* **React** (para criar as telas visuais)
* **TypeScript** (para garantir que o código funcione sem erros de digitação)
* **Vite** (para fazer o sistema carregar de forma super rápida durante o desenvolvimento)
* **CSS Modules** (para organizar as cores, fontes e estilos das páginas)

## 💾 Onde as informações ficam salvas?
Todos os dados adicionados no sistema ficam guardados na memória do seu próprio navegador (usando o recurso chamado *localStorage*). 

> **Dica:** Na primeira vez que você abrir o sistema, ele já virá preenchido com alguns clientes e compromissos de teste para você ver como funciona na prática.
